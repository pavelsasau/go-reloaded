# Go Reloaded
## Description
Go Reloaded est un programme écrit en Go qui lit un fichier texte, applique plusieurs transformations au texte, puis écrit le résultat dans un nouveau fichier.
Le programme permet de modifier certains mots grâce à des balises spéciales comme `(up)`, `(low)`, `(cap)`, `(hex)` et `(bin)`.
## Utilisation
Pour lancer le programme :
go run . sample.txt result.txt
